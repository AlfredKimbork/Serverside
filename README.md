# PHP CRUD — Server-Side Project

A small school project built with **PHP and MySQL** to demonstrate server-side programming.

## Features

* Create people
* View people
* Edit people
* Delete people

## Technologies

* PHP
* MySQL
* PDO
* HTML
* CSS
* JavaScript

## Server-Side

PHP handles form submissions and communicates with the MySQL database using **PDO prepared statements**.

The project demonstrates the four basic CRUD operations:

**Create → Read → Update → Delete**
